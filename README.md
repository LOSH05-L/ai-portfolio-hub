# ⚡ AI Intelligence Hub: Full-Stack Machine Learning Suite

An enterprise-grade, full-stack predictive modeling web application featuring real-time glassmorphic UI inference, a high-performance **FastAPI** backend, and a **Random Forest / Linear Regression** core built for modern AI/ML deployment workflows.

---

## 🚀 Architecture & Tech Stack

* **Frontend:** HTML5, CSS3 (Glassmorphism, Neon Gradients, Responsive Flexbox Grid), JavaScript (ES6+ Asynchronous Fetch API)
* **Backend:** Python, FastAPI, Uvicorn (CORS enabled, RESTful routing)
* **Machine Learning & Data Science:** Scikit-Learn, Pandas, NumPy
* **Deployment & Hosting:** Render (Backend Cloud Service), GitHub Pages (Frontend static hosting)

---

## 📊 Included Models & Engines

1. **Wine Cultivar Classification Engine**
   * **Algorithm:** Random Forest Classifier
   * **Dataset:** Wine Recognition Dataset (`sklearn.datasets.load_wine`)
   * **Features:** 13 chemical composition metrics (Alcohol, Malic Acid, Flavanoids, etc.)
   * **Performance:** 100.00% test accuracy on held-out benchmark splits.

2. **California Housing Estimation Engine**
   * **Algorithm:** Linear Regression (Standardized via StandardScaler)
   * **Dataset:** California Housing Dataset (`sklearn.datasets.fetch_california_housing`)
   * **Features:** 8 demographic and geographic indicators (Median Income, House Age, Average Rooms, etc.)
   * **Performance:** Evaluated via Mean Squared Error (MSE) and $R^2$ Score.
